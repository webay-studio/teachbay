# 제품 방향과 범위

## 핵심 사용자와 흐름

개인 강사가 자신이 가진 문제 자료로 다음 수업 시험지를 빠르게 만드는 서비스다. 학원 전체 관리 프로그램으로 확장하지 않는 것이 현재 방향이다.

기본 흐름: 진입 → 문제 등록 → 내 문제에서 선택 → 시험지 편집·출력 → 만든 시험지 다시 열기.

서비스명은 초기 teachway에서 **teachbay**로 변경했다. 로컬 프로젝트 폴더 이름은 여전히 teachway다.

## 초기 요구사항

- 과목·단원·난이도·태그는 필수 입력이 아니다.
- 이미지 중심으로 문제를 저장하고 시험지를 만든다.
- 기본 설정만으로 출력 가능하며 세부 설정은 접어서 제공한다.
- 원본 이미지 비율·품질을 보존한다.
- 저장된 시험지는 원본 문제 삭제·수정에 영향받지 않는 스냅샷이어야 한다.
- 문제 이미지와 영구 자료는 IndexedDB에 보관한다. 전체 이미지를 Base64로 localStorage에 저장하지 않는다.
- 서버 저장·동기화·보안 인증이 구현된 것처럼 표현하지 않는다.
- 브라우저 저장 안내를 유지한다.
- 인증·데이터 접근·인쇄 로직은 화면에서 분리한다.

## 화면

- `/login`: 현재는 회원가입 없이 브라우저 작업실로 진입하는 화면.
- `/questions`: 내 문제.
- 2026-09-23 등록 진입 변경: 빈 보관함 전체를 클릭해 파일을 선택하거나 파일을 드롭하면 등록 모달이 열리고 해당 파일을 바로 처리한다. 파일 선택 취소 시 현재 화면을 유지한다.
- `/questions/new`: 문제 등록. 클라이언트 이동 시 인터셉트 모달, 직접 접속/새로고침은 `/questions` redirect(2026-09-23 변경).
- `/exams/new`: 시험지 만들기.
- `/exams`: 만든 시험지.
- `/exams/[id]`: 저장한 시험지 열기·재출력.

초기 기획은 네 개 내비게이션이었으나 현재 작업 화면 헤더는 ‘내 문제 / 만든 시험지’이며 등록은 화면 내 버튼에서 접근한다.

## 최신 저장 단위 · 2026-09-23
- 지문 선택 → 시작/끝 문제 지정 → 명시적 묶음. 보관함 1항목, 지문→문제 순서의 개별 fragments 보존; 시험지에서도 1 snapshot.
- 일반 공통자료 연결은 기존 독립 선택 유지. 명시적 묶음만 전체 선택/해제; 해제·undo 가능. 기존 자료 자동 재작성 없음.

## 기능 범위의 변화

초기에는 JPG·PNG·WebP 등록만 요구했으나 이후 PDF 및 한글 문서 등록으로 범위가 확대됐다. PDF 문항 분리 엔진이 현재 서비스의 중요한 기능이 됐다. 한글 파일 파싱·변환의 실제 범위는 코드 및 별도 검증으로 확인해야 한다.

사용자는 샘플·데모 문구와 불필요한 UI를 제거하도록 요청했다. 현재 진입 문구는 ‘회원가입 없이 시작’이며 실제 보안 인증과 구분한다. 로그아웃으로 저장 자료를 삭제하지 않는다.

## 무료·유료 논의

초기 요구는 제작·편집·출력을 무료로 제공하고 워터마크·출력 횟수 제한·유료 잠금을 두지 않는 것이었다. 이후 사용자는 무료 추출의 문항 수 제한 및 자동 추출 품질 미보증, 저장된 문제의 빠른 시험지 제작을 상품 방향으로 논의했다. 이는 가격제 구현 완료를 의미하지 않는다.

유료 후보는 이미지 품질 개선, 편집 가능한 텍스트·수식 변환 등이다. AI 타이핑, 결제·구독, 학생·반 관리, 조직 권한은 현재 범위 밖이다.

## 저작권 관련 논의

공개된 수능·모의고사 자료를 서비스에 미리 넣는 방안을 논의했다. 무료 제공이나 출처 표기만으로 복제·배포 허락이 자동 확보되는 것은 아니라는 쟁점이 있었다. 서비스 배포 권한이 확보됐다고 기록하지 않는다. 실제 자료 제공 정책 확정 시 권리·이용 조건을 별도로 검토해야 한다.
