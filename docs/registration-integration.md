# 등록 페이지 엔진 통합 — 2026-09-21

## 변경

- 정식 `/questions/new`에 검증된 `lib/pdf-region-engine`을 연결했다. `/question/new`는 이 경로로 이동한다.
- `pdf-registration.ts`가 엔진 결과를 등록 데이터로 변환한다. 기존 번호·공통 지문·여러 페이지 조각을 유지하며 재분할하지 않는다.
- `document-review.tsx`는 모달 대신 페이지 안에 원본과 문제 목록을 표시한다. 문제 선택, 필수 자료 자동 포함, 경계 조절, 합치기, 나누기, 원본 확인 후 등록을 제공한다. 검토 접기/재열기에서 선택을 유지한다.
- `prepare-registration.ts`가 확인한 항목의 원본 문서, 페이지 변환, 개별 조각, 관계를 저장 준비한다. `saveQuestions`의 IndexedDB 트랜잭션을 재사용한다.
- 이미지 자르기도 인라인으로 바꿨다. HWP/HWPX 기존 경로는 유지한다.
- 제거: `app/lab/pdf-regions/`, 실험 전용 `point-distribution.tsx`, `shape-ink-review.tsx`, 폐기된 화면에 의존한 `verify-lab-editor.mjs`, `verify-lab-regions.mjs`, `render-lab-regression.mjs`.
- 엔진 회귀 도구, 필요한 호환 내보내기, 다른 화면의 모달은 유지한다.

## 한계

이번 통합은 영역 판정 알고리즘을 바꾸지 않았다. 한국지리 20번 하단 안내 상자 포함 등 기존 오류가 남는다. 스캔 OCR 전체 재실행, HWP/HWPX의 새 브라우저 회귀, 실제 인쇄 창, 저장 공간 부족, 모바일 검토 화면 전체 조작은 이번에 검증하지 않았다. 공통 지문과 다중 조각의 변환·선택은 단위 테스트로 검증했고, 이번 브라우저 저장 사례는 단일 조각 문항이다. 검증용 서버는 확인 후 종료한다.

## 등록 UX 재정리

검토 화면의 큰 제목·단계 표시·샘플 목록을 제거하고 원본/문제 목록 작업 공간을 화면 높이에 맞췄다. 원본은 전체 페이지를 맞추고 문제 목록만 독립 스크롤한다. 문제 미리보기는 전체 영역 맞춤과 크게 보기를 제공한다. ‘파일 추가’와 ‘문제 직접 추가’를 구분한다. 묶기 체크박스는 영역 묶기 모드에서만 보인다. 확인은 하단 한 번으로 통합했으며 검토→등록 목록→저장의 중복 단계를 없애 PDF 검토 화면에서 IndexedDB에 바로 저장한다. 다른 대기 파일은 보존한다.

Chrome에서 한국지리 PDF 20문항 표시, 선택 유지, 한 번 확인 후 직접 저장, 원본 전체/저장 버튼의 화면 내 배치, 직접 추가 모드 진입, 모바일 검토 화면 가로 넘침 없음 및 새로고침 후 저장 자료 유지를 검증했다. 스캔 OCR은 재실행하지 않았다. 알고리즘은 변경하지 않았다.

## 파일 목록 중심 등록

등록 화면의 상단 헤더·제목·설명·드롭존을 제거하고 파일 선택 버튼과 파일 목록으로 정리했다. 여러 파일을 선택해 순차 분석하고, 목록에서 파일을 눌러 검토 화면을 전환한다. `onDraftChange`로 문항 수정·선택을 부모 상태에 보존한다. 검토 중 파일을 추가할 수 있으며 저장 중에는 전환을 막는다. 한 파일을 저장해도 나머지 대기 파일은 남는다. 작업 화면의 상태는 새로고침까지 영구 보존되는 초안 기능은 아니다.

Chrome에서 같은 한국지리 PDF를 A/B 두 파일로 업로드하여 각 20문항, A에서 16번만 선택→B→A 선택 유지, A 저장 뒤 B 목록 유지, 새로고침 후 저장된 1문항과 원본 PDF 보존을 확인했다. 색상 처리는 기본 설정으로 실행했다. 원본·추가·저장 버튼 위치와 모바일 검토 가로 넘침도 검사했다. 빌드 및 63개 테스트 통과. 검증 서버 종료.
