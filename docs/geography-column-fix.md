# 한국지리 왼쪽 단 누락 수정

2026-09-21. `physicalRegions()`에서 세로 잉크 투영을 단 외곽선으로 바로 사용하던 부분을 수정했다. 서로 떨어진 상자·본문의 검은 픽셀 합계가 페이지 높이 40%를 넘으면 외곽선으로 선택되어, 4쪽 왼쪽 단 시작이 x=0.12276으로 밀렸다. 실제 16·17·18번 시작은 x=0.10439이고 `combineRegions()`의 inFlow 필터가 이 글줄을 제외했다.

외곽선 후보에 한해 긴 연속 세로선 근거를 요구한다. 스캔의 작은 끊김은 허용하되 서로 떨어진 상자를 하나의 선으로 합산하지 않는다. 중앙 분할 제안과 기존 번호 검증, 문항 연결, OCR 정책은 변경하지 않았다. 페이지나 문항 위치를 하드코딩하지 않았다.

- 실제 브라우저 PDF 업로드: 이전 17문항, 수정 후 1~20번 20문항. 4쪽 왼쪽 16·17·18번 복구. 양쪽 모두 OCR 0회.
- 한국지리 4쪽 오버레이에서 복구된 본문·그림·선택지 확인.
- 기존 국어: 새 physical 계산과 저장된 OCR 재사용으로 323개 검사 통과. 문항·지문·화면 그룹이 이전과 동일. 전체 OCR을 다시 실행한 검증은 아니다.
- 수학 1111/2222: 같은 방식의 재계산으로 각각 104/107개 검사 통과.
- 단위 테스트 57개, 타입 검사, production build 통과.
- 별도 남은 문제: 한국지리 20번 아래 확인 사항 상자가 현재 문항 범위에 포함된다. 이번 단 누락 수정으로 해결됐다고 보고하지 않는다.
